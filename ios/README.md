# Exercise Studio for iPhone

Personal-use iOS 17+ companion with SwiftUI app settings and a persistent WKWebView. The workout interface, 3D demos, plans, records and sync rules remain the canonical web app served by the Pi. There is no copied HTML, JS bundle or second workout implementation inside the iPhone app.

The default address is `https://anujrpi.tail549492.ts.net/exercise/`. Keep Tailscale enabled on your iPhone and the Pi running. Sign in inside the app. Credentials are not embedded in the project. Safari and the companion have separate cookies and device queues; saved Pi records are shared. The companion must connect on first launch. Do not assume the Safari offline worker works identically in WKWebView; offline reopening, timers and queued saves still require physical-device verification. Timers do not receive extra background execution from this shell.

Native features: persistent website session, HTTPS connection settings, reload confirmation, keep-screen-awake preference while active, system file sharing for WKDownload exports, normal iOS file selection for restore/photos, JavaScript confirmation dialogs, and external links opened outside the app. There are no TLS bypasses, ATS exceptions or native JavaScript bridges. Same-origin authentication redirects remain in the app.

## Open and install

Open `ExerciseStudio.xcodeproj` in Xcode, select the ExerciseStudio scheme and your connected iPhone, then Run. Automatic signing is configured with Anuj Jha's existing team `4YQ5449J68`. If provisioning changes, choose the active paid team under Signing & Capabilities. No App Store submission is needed for personal installation.

`project.yml` is the canonical project configuration; the checked-in Xcode project is generated by XcodeGen. Edit Swift sources normally. Regenerate project structure/settings with `xcodegen generate --spec ios/project.yml` from the repository root. Do not hand-maintain divergent settings in the generated project.

The app icon uses the existing web app icon enlarged to Apple's 1024px asset size. To change it, edit the original icon and regenerate the asset. Builds and signing profiles stay outside source control.

## Verify

The unit tests cover HTTPS address validation and origin restrictions. The UI tests check native settings; the authenticated library test skips unless a local test runner supplies `STUDIO_TEST_PASSPHRASE`. Never commit credentials to source or scheme files.

Simulator builds use `CODE_SIGNING_ALLOWED=NO`; physical-device builds require the selected developer team. This app was built with Xcode 27.0, tested in the iOS 27 simulator, and signed/installed on the connected iPhone 17 Pro. Installation and launch are verified; sign-in and workout interactions on that physical phone are still a user check.

Before relying on it during exercise, check sign-in, the 3D demo and controls in both themes, log/edit/undo a test set, pause/resume, CSV/JSON/photo archive sharing, photo selection, restore confirmation, close/reopen, airplane-mode reopening/queueing, reconnection and conflict resolution. Preserve pending edits before uninstalling; uninstall removes the companion's local queue and session. Server records remain on the Pi.

The native archive is a personal companion, not a public App Store release. Public distribution would need a separately scoped accessibility/privacy/review and offline experience pass.
